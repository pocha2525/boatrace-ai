- 学習: 成績の本番進入・本番気象を当該レースの入力に流用しない。展示進入で過去の実コース成績を照会。未観測の気象は欠損。比較用の現行材料モデルも同じ学習期限で作り直す。検証期間でコメント有無と確率補正を選び、未使用の最終期間で1回だけ比較する。日単位の再標本化で改善の下限を確認し、件数・観測率が足りなければ採用しない。
- 即時同期: CSVをpushした後にSHEET_HOOKを呼ぶ処理を追加。未設定時は定期同期を維持し、未有効と明示。GASは同期できた場合だけokを返し、ロック中はbusyを返す。
