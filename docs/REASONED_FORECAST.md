# ChatGPTの判断手順を使う並行予想

ユーザーの「君の予想も反映」を受け、成績の表示に加えて予想を生成する処理を追加した。
`reasoned_forecast.py` が公式から取得した同じ6艇の特徴量を読み、オッズ取得前に4点を出す。
LightGBMの120通りの確率、固定67特徴量候補、実運用の買い条件は保持する。

## 今回、予想処理へ反映した判断

- 1着候補の評価と、2・3着候補の評価を分離する。1号艇を自動的に頭にしない。
- 能力、コース適性、今節、機械の成績、展示の足、スタート、コメントを別の材料群として比較する。
- 今節の材料は3走以上ある場合に使う。通常ST・今節ST・展示STを一緒に比較し、展示Fを本番F扱いしない。
- 展示タイムと一周・回り足・直線のうち、6艇分そろった項目を比較する。機率ゼロと欠損は弱い足と断定しない。
- 内2・3艇と外4・5・6艇の長短を対で残す。外艇を3着だけに限定する規則を置かず、2・3着の20通りを比較する。
- 最終4点に同じ相手が3点以上含まれる集中を記録する。集中しているだけで買い目を機械的に増やさない。

各項目は6艇内の順位へ変換し、同じ群の項目を平均、利用できる群を等しく平均する。
コース適性の2着側は過去2着以内率−1着率、3着側は3着以内率−2着以内率を使う。
全艇でそろった同じ項目だけを使い、欠損艇の少ない材料だけで相対評価を上げない。
必須の能力・コース・通常/今節/展示STのいずれか・展示タイムが欠けると生成を保留する。
選んだ1着候補の下で2・3着の順位指数を平均し、上位4点を保存する。同点は艇番で固定する。

この等配分の順位規則は、過去の的中に合わせて最適化した学習済み重みではない。
判断の一部を数値化した検証用の限定規則であり、ChatGPTの裁量全体を再現したものではない。
映像、深い進入、潮位、自由文コメントの文脈、全国から1日1Rを選ぶ裁量は今回の規則に含まれない。
取得済み数値のコメント特徴量だけが利用可能で、未取得のコメントを推測して埋めない。

## 時点の証拠と採点

`predict.py` の展示確認後、オッズ取得前に規則予想を固定する。
`market_YYYYMMDD.jsonl` の `reasoned` に4点・材料・群別評価・相手比較・集中・コードハッシュ・入力ハッシュ・時刻を残す。
特徴量観測≦規則確定≦オッズ取得開始≦取得完了≦締切2分前を確認できる記録だけを比較する。
実行開始前のレースへ遡って規則予想を加えず、同じレースは最初の市場観測で固定する。

`policy_replay.csv` の `chatgpt_rules_v1_four` はその4点各100円の仮想精算。
払戻・返還・未確定は他の方式と同じ公式結果で扱う。
順位指数を的中確率や期待値に変換せず、この方式の対数確率欄は空欄にする。
実在するChatGPTの展示後最終4点・仮想1万円配分は `manual_forecasts.jsonl` の別記録として採点する。
両者を混ぜて「ChatGPTの実成績」と表示しない。

## スマホ通知への表示

既存の買い・朝候補の見送り通知に「私の判断ルール｜検証4点」を追加する。
締切前の市場記録に保存できた4点だけを読み、参考オッズ、1着候補、実際に使った材料群、
採用相手の内外比較、相手への集中、オッズ取得前の予想固定時刻を表示する。
数値指数を的中確率や期待値へ変換せず、各100円・計400円の仮想検証と明記する。
必要なデータや時点の記録が不足する場合は保留を表示し、4点を補わない。

本番AIの買い目・見送りと区別して同じ通知の本文へ併記し、通知数と1レース1通知のIDは増やさない。
送信済みレースの再送、締切後の予想通知、検証4点の本番投資への算入は行わない。
朝の候補以外の見送りは従来どおり通知しない。既存の購入条件・点数・締切ガードは維持する。

## 本番への採用

新しい規則の利益は未実証。固定候補の採用期間やハッシュは変更せず、規則の成績で67特徴量候補を合格にしない。
規則のコードハッシュごとに将来記録を蓄積し、別の未使用期間で検証するまで本番買い目の自動上書きは行わない。
この変更は新しい予想生成・記録・仮想採点の実装であり、回収率が上がったという結果ではない。
